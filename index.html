About me

I'm Juzail Zabrin, a Computer Science student and developer from Colombo who turns ideas into real, working apps — from a car marketplace in your pocket to an AI that explains what it sees in a chest X-ray.

I started with HTML and CSS, built WordPress sites, and took on freelance frontend work. Today I spend most of my time in React and React Native, with Node.js and MySQL on the backend when a project needs it.

I care about the small stuff: interfaces that feel quick, layouts that work on every screen, and code someone else can pick up. Right now I'm finishing my degree at IIT and building my final-year project on explainable AI for TB screening.

Explainable TB detection In progress

Final-year project — AI that screens chest X-rays and shows why

Grad-CAM heatmapRefer to doctor

A web app that uses a pretrained deep-learning model to flag possible tuberculosis in chest X-rays — and, unlike most tools, shows a Grad-CAM heatmap so doctors can see exactly which area the model looked at.

  • Transfer learning (ResNet50 / DenseNet121)
  • Visible Grad-CAM explanation layer
  • Confidence-based doctor-referral flag
  • Cross-dataset testing on TBX11K
